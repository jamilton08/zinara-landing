# Zinara Landing

Landing page for Zinara — *You Are The Game*.

Built with Vite + React, with a live MoveNet pose demo (TensorFlow.js) and Three.js visuals.

## Stack

- Vite 6 + React 18
- `@tensorflow-models/pose-detection` (MoveNet, WebGL backend)
- Three.js
- React Router v7

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview   # to test the production build locally
```

Output goes to `dist/`.
